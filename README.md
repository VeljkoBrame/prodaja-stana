# Prodaja stana

Jednostavan sajt-oglas za jedan stan. Bez build koraka i bez zavisnosti.

## Personalizacija

1. Fotografije stavite u folder `slike/` (preporuka: horizontalne, ~1800px širine, JPG).
2. U `podaci.js` upišite naslov, cenu, opis, karakteristike, putanje do slika i kontakt.
   Prva slika u listi je naslovna.

## Pregled lokalno

Samo otvorite `index.html` u browseru.

## Objavljivanje

Ceo folder se može postaviti na bilo koji statički hosting
(Netlify Drop, GitHub Pages, Cloudflare Pages, Vercel) — prevucite folder i gotovo.
